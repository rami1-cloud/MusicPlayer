# مشغل الموسيقى (Android)

تطبيق أندرويد بسيط لتشغيل ملفات الموسيقى الموجودة على الجهاز، مكتوب بلغة Kotlin.

## المميزات
- يعرض قائمة بكل الأغاني الموجودة على الجهاز (يقرأها عبر MediaStore).
- تشغيل / إيقاف مؤقت.
- التالي / السابق.
- شريط تقدّم (Seek Bar) لمعرفة موضع التشغيل والتحكم به.
- يطلب إذن الوصول لملفات الصوت تلقائيًا عند أول تشغيل.

## كيفية فتح المشروع
1. افتح **Android Studio** (يفضّل أحدث إصدار).
2. اختر **Open** ثم حدد مجلد `MusicPlayer` الذي يحتوي هذا الملف.
3. انتظر حتى ينتهي Gradle من المزامنة (Sync) — سيقوم Android Studio بإنشاء ملفات الـ Gradle Wrapper تلقائيًا إن لم تكن موجودة.
4. وصّل هاتفك أو شغّل محاكي (Emulator) ثم اضغط **Run** ▶️.

## بنية المشروع
```
MusicPlayer/
├── app/
│   ├── build.gradle.kts
│   └── src/main/
│       ├── AndroidManifest.xml

└── settings.gradle.kts
```

## ملاحظات
- الحد الأدنى لإصدار أندرويد المدعوم: Android 6.0 (API 23).
- يستخدم `MediaPlayer` الأساسي في أندرويد — يمكن لاحقًا الترقية لمكتبة **ExoPlayer/Media3** لتشغيل أكثر احترافية (تشغيل في الخلفية، إشعارات تحكم، إلخ).
- لتشغيل الموسيقى في الخلفية مع إشعار تحكم، يلزم إضافة `Service` منفصل — هذا غير مضمّن حاليًا للحفاظ على بساطة المشروع.

## أفكار للتطوير لاحقًا
- إضافة تشغيل في الخلفية عبر `MediaSessionService`.
- إضافة خاصية البحث ضمن قائمة الأغاني.
- إضافة قوائم تشغيل (Playlists) وحفظها.
- إضافة صورة الغلاف (Album Art) لكل أغنية.
